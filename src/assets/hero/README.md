# Homepage hero photo (optional)

Put **one** landscape photo of the company's own work here (e.g. `hero.jpg`, at least
1920 px wide). It appears on the right side of the homepage hero. If this folder has no
photo, the hero uses the typographic layout with the technical-drawing background.
Change the alt text in `src/pages/[lang]/index.astro` (`heroAlt`).
