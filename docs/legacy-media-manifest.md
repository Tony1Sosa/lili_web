`https://www.railing-inox.com/wp-content/uploads/` on the old server. The build environment
could not download them, so none of them are in this repository yet.

**How to migrate:** take the original files from a WordPress backup (FTP or hosting file
manager). Use the full-size originals, not the `-150x150` or `-1024x768` thumbnails. Sort each
photo into the matching project folder under `src/assets/projects/<project-slug>/`. See
[`CONTENT-GUIDE.md`](CONTENT-GUIDE.md).
